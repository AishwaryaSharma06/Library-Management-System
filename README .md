# Library Management System
A simple and beginner-friendly **Library Management System** built usinf **python**.

This project helps manage library books by allowing users to:
-Add books
-View available books
-Issue books
-Return books
-Save data permanently using JSON file handling

# Features
-Add New Books
-View All Books
-Issue Books
-Return Books
-Store Data Permanently
-Simple Menu Driven Interface
-Beginner Friendly Python Project

# Technologies Used 
-Python 3
-JSON File handling
-Lists
-Dictonaries
-VS Code
